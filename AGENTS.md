# Using this repository

This is an asset library, not an application. There is no build, no test suite
and no code to run. If you are an agent building a game, read this file, then
query `index/` to pick assets.

## License: no constraints

Every file is **CC0 1.0** (public domain equivalent). Use anything, commercially
or not, modified or not. No attribution, no license file to ship, no per-asset
tracking. Provenance for each pack is in its `SOURCE.md` and in `catalog.json`.

## Layout

```
<genre>/<pack>/          the assets, plus a SOURCE.md per pack
catalog.json             217 packs: id, title, genre, genres, tags, license, path
index/                   generated manifests - query these, do not walk the tree
README.md                human-facing index
```

## Filtering: two independent axes

Folder names are a filing convention, not a classification. Every catalog entry
carries both axes — **filter on these, never on the folder**:

| Field | Means | Values |
|---|---|---|
| `type` | what the pack **is** | `2d` `3d` `audio` `music` `font` `material` `hdri` |
| `genres` | what it **depicts** | `fantasy` `sci-fi` `shooter` `weapons` `horror` `post-apocalyptic` `western` `platformer` `racing` `puzzle` `prehistoric` `urban` `nature` `industrial` `vehicles` `characters` `props` `tiles` `ui` `sports` `food` `material` `hdri` |

A pack carries every genre that applies, so `medieval-fantasy-pack` is
`type: 2d, genres: [fantasy, ...]` and `fantasy-music` is `type: music,
genres: [fantasy]`. Asking for "fantasy" returns sprites, 3D kits, sound effects
and music together — which is what building a themed game needs.

`index/by-genre.json` is a prebuilt `genre -> [pack ids]` and `type -> [pack
ids]` lookup, so filtering is a dict access rather than a scan.

The legacy `genre` field (singular) still exists and still mirrors the folder.
It is kept only so paths stay stable — **do not filter on it**. It will tell you
a 2D fantasy pack is `"2d"`.

## index/

Generated by `tools/build_index.py`; rerun it after adding packs.
`tools/reindex.py` regenerates `catalog.json` and the README index.

| File | Contents |
|---|---|
| `index/packs.json` | Every pack with file counts by extension, total bytes, preview image path, its sprite sheets, and total audio seconds. Superset of `catalog.json`. |
| `index/spritesheets.json` | All 71 packed sprite sheets: sheet path, atlas path, frame count, pixel dimensions. |
| `index/audio.json` | All 655 sound and music files with duration in seconds. |
| `index/by-genre.json` | `genre -> pack ids` and `type -> pack ids` lookups. |

### Picking assets

```python
import json
packs = json.load(open("index/packs.json"))["assets"]

# themed packs - sprites, models, sfx and music together
fantasy = [p for p in packs if "fantasy" in p["genres"]]

# narrow to one format
fantasy_2d = [p for p in fantasy if p["type"] == "2d"]

# or skip the scan entirely
ids = json.load(open("index/by-genre.json"))["genres"]["shooter"]

# packs that ship a ready-to-slice sheet
sheeted = [p for p in packs if p["sprite_sheets"]]

# music long enough to loop under gameplay
audio = json.load(open("index/audio.json"))["files"]
loops = [a for a in audio if a["seconds"] and a["seconds"] > 60]
```

## Sprite sheets

71 sheets, 42 with an atlas. Two conventions:

- **Atlas XML** (Kenney packs). `<TextureAtlas>` with one `<SubTexture
  name= x= y= width= height=>` per frame — absolute pixel rects, no trimming or
  rotation. Note the atlas declares `imagePath="sheet.png"` as a leftover
  placeholder; the real sheet is the `.png` matching the XML's own basename.
  `index/spritesheets.json` already resolves this, so use the `sheet` field.
- **No atlas** (Superpowers packs, `0-*.png`). Uniform grid — derive the cell
  size from the image dimensions and frame count.

Most packs also ship the individual frames as loose PNGs next to the sheet, so
you can skip atlas parsing entirely if that is easier.

## Formats

PNG and SVG art, OGG audio, TTF fonts, GLB/GLTF/OBJ/DAE/FBX models, HDR
environment maps, and PBR texture sets (colour / normal / roughness / AO).

## Conventions when adding packs

One folder per pack under a genre, containing the files plus a `SOURCE.md`
recording author, license, tags and origin. Add a matching entry to
`catalog.json`, then run `tools/retag.py` (recomputes `type`/`genres`),
`tools/reindex.py` and `tools/build_index.py`. Text files in this repo use CRLF endings — preserve them or the
diffs balloon. Only CC0 assets belong here; the blanket guarantee above is the
point of the repo, so do not add anything with attribution or share-alike terms.

Commit only art, model, audio, font and text files. Executable and script types
(`.exe`, `.dll`, `.bat`, `.ps1`, `.js`, `.vbs`, `.swf`, ...) are stripped.
